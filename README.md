## 🌐 Sobre o portfólio

O **Dev Anísio** é meu espaço profissional na internet. Foi desenvolvido para reunir meus principais trabalhos, apresentar minhas competências e facilitar conexões com clientes, empresas e outros profissionais da tecnologia.

A identidade visual foi construída a partir do protótipo *Portfólio Principal 2.0*, desenvolvido no Figma.

O projeto utiliza HTML5, CSS3 e JavaScript puro, priorizando uma estrutura leve, organizada, responsiva e sem dependências de frameworks.

### ✨ Funcionalidades

- **Interface personalizada:** identidade visual própria baseada em prototipagem no Figma.
- **Tema claro e escuro:** alternância de aparência com preferência salva no navegador.
- **Animações interativas:** elementos visuais que respondem à navegação e às interações.
- **Navegação responsiva:** menu adaptado para dispositivos móveis.
- **Integração com WhatsApp:** atalhos de contato com mensagens personalizadas.
- **Projetos dinâmicos:** apresentação de projetos e integração com repositórios do GitHub.
- **Carrossel de depoimentos:** navegação por setas, indicadores e gestos de arraste.
- **Clientes e parceiros:** apresentação de marcas e empresas com as quais tive contato profissional.
- **Modais informativos:** janelas de termos e política de privacidade.
- **Acessibilidade:** estrutura semântica e recurso para pular diretamente ao conteúdo.

## 📂 Estrutura do projeto

```text
portfolio/
│
├── index.html
│
├── assets/
│   ├── css/
│   │   └── style.css
│   │
│   ├── js/
│   │   ├── config.js
│   │   └── main.js
│   │
│   └── img/
│       └── imagens e recursos visuais
│

```

### Organização dos arquivos

- `index.html`: estrutura principal e seções do portfólio.
- `assets/css/style.css`: estilos, responsividade e animações.
- `assets/js/config.js`: configurações de redes sociais, contato, projetos e depoimentos.
- `assets/js/main.js`: funcionalidades e interações da aplicação.
- `assets/img/`: imagens, ícones e elementos visuais.

## ⚙️ Como executar localmente

O projeto utiliza tecnologias nativas da Web e não necessita de instalação de dependências ou processo de build.

**1. Clone o repositório:**

```bash
git clone https://github.com/anisiodiogo/portfolio.git
```

**2. Acesse a pasta:**

```bash
cd portfolio
```

**3. Execute o projeto:**

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server no Visual Studio Code.

## 🔧 Configuração

As principais informações dinâmicas do portfólio podem ser alteradas no arquivo:

```text
assets/js/config.js
```

Nele, você pode atualizar:

- Número e mensagem do WhatsApp.
- E-mail e telefone.
- Links das redes sociais.
- Usuário do GitHub.
- Projetos em destaque.
- Depoimentos e informações dos clientes.

A integração com o GitHub permite apresentar automaticamente repositórios identificados com o tópico `portfolio`.

---

## 🚀 Publicação

O projeto pode ser hospedado gratuitamente pelo GitHub Pages.

1. Envie os arquivos para seu repositório GitHub.
2. Acesse **Settings → Pages**.
3. Selecione a branch `main`.
4. Escolha a pasta `/root`.
5. Clique em **Save**.

Após a publicação, o site poderá ser acessado pelo endereço:

```text
https://anisiodiogo.github.io/my-portfolio/
```
